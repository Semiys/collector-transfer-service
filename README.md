# Хаб Коллекционера — сервис переноса коллекций

Учебный проект по дисциплине «Методы и средства проектирования информационных систем». Версия 0.0.1 показывает первую страницу сервиса. Планируемая задача проекта — помочь коллекционерам перенести записи из таблиц и текста в мобильное приложение DomCollection.

## Технологии

- Node.js 24.21.0
- Express 5.2.1
- Один Docker-контейнер, порт 8080

## Запуск опубликованного образа

Публичный образ: https://hub.docker.com/r/semiys/mispisit-lab1/tags

docker pull semiys/mispisit-lab1:0.0.1
docker run --rm -p 8080:8080 semiys/mispisit-lab1:0.0.1

После запуска откройте http://localhost:8080. Должны отображаться название, описание, версия и статус разработки. Образ скачивается без входа в Docker Hub.

## Локальная сборка из исходного кода

docker build -t mispisit-lab1:0.0.1 .
docker run --rm -p 8080:8080 mispisit-lab1:0.0.1
