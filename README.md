# Хаб Коллекционера — сервис переноса коллекций

Учебный проект по МиСПИСИТ. Текущая версия 0.0.1 показывает первую страницу сервиса.

## Состав

- Node.js 24.21.0
- Express 5.2.1
- Один Docker-контейнер, порт 8080

## Проверка на компьютере с Docker

docker build -t mispisit-lab1:0.0.1 .
docker run --rm -p 8080:8080 mispisit-lab1:0.0.1

Откройте http://localhost:8080. Должны отображаться название, описание, версия и статус разработки.

## Публикация для преподавателя

После регистрации в Docker Hub и проверки локального запуска:

docker tag mispisit-lab1:0.0.1 ВАШ_ЛОГИН/mispisit-lab1:0.0.1
docker login
docker push ВАШ_ЛОГИН/mispisit-lab1:0.0.1

Замените ВАШ_ЛОГИН на свой логин и впишите итоговую ссылку на публичный образ сюда и в отчёт. Проверка опубликованного образа:

docker pull ВАШ_ЛОГИН/mispisit-lab1:0.0.1
docker run --rm -p 8080:8080 ВАШ_ЛОГИН/mispisit-lab1:0.0.1
