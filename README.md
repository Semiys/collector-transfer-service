# Хаб Коллекционера — сервис переноса коллекций

Учебный проект по дисциплине «Методы и средства проектирования информационных систем». Текущая версия исходников — 0.1.0. Сервис принимает CSV, XLSX, JSON и структурированный TXT, показывает соответствие полей и создаёт ZIP для DomCollection.

## Что уже работает

- Чтение таблиц CSV/XLSX, списков моделей JSON и текстовых списков вида `A01 Название — описание` (в том числе вставленных на странице).
- Просмотр столбцов и первых записей до конвертации.
- Перевод цены покупки из EUR в RUB по [официальному курсу Банка России](https://www.cbr.ru/development/sxml/) с указанием даты курса в заметках.
- Загрузка личных фотографий Hunt64 по ссылкам из столбца `My Photo URL`, преобразование WebP/PNG/JPG в JPG.
- Заглушка для отсутствующего или недоступного фото. Дата переноса используется для записей без даты покупки и помечается в заметках.
- ZIP с `collection.json` и `photos/*.jpg` по формату импорта мобильного приложения.
- Бесплатная инструкция `/guide` с готовым промптом для DeepSeek. Ответ можно вставить прямо на главной странице: сервис покажет все модели, потребует подтверждения проверки и сам создаст ZIP.
- Админ-панель `/admin` для списка API-ключей владельцев, согласившихся участвовать. Ключи шифруются на диске; в интерфейсе видны только последние четыре символа. Кнопка «Проверить» запрашивает состояние ключа в OpenRouter.
- Пробное распознавание свободного текста через `openrouter/free`: администратор выбирает один включённый ключ, получает список до 100 моделей и передаёт его на полный предпросмотр перед ZIP. Сервис не переключается между ключами автоматически. Цена и валюта требуют проверки человеком.

Свободный текст и сообщения Telegram можно разобрать вручную через DeepSeek по инструкции `/guide`. Автоматическое распознавание нашим OpenRouter-маршрутом доступно только администратору; пользовательский поток с оплатой и ограничениями расходов ещё не реализован. Фото с произвольных сайтов и входные ZIP не поддерживаются. Архив добавляет модели в приложении; автоматического поиска дублей при импорте нет. Лимиты одного переноса: 8 МБ входной файл, 300 моделей, 100 МБ выходной ZIP. Для OpenRouter: до 20 000 символов и 100 моделей за запрос.

## Разработка и проверка

Инструкция для второго компьютера: [docs/SECOND_COMPUTER_SETUP.md](docs/SECOND_COMPUTER_SETUP.md).

```sh
npm ci
npm test
npm start
```

Откройте `http://localhost:8080`. Для Docker используйте `docker build -t collector-transfer-service:0.1.0 .` и `docker run --rm -p 8080:8080 collector-transfer-service:0.1.0`.

Образ `semiys/mispisit-lab1:0.0.1` в Docker Hub относится к первой лабораторной и содержит только исходную страницу. Новая версия сервиса в Docker Hub пока не опубликована.
