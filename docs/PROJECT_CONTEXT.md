# Контекст проекта

## Назначение

«Хаб Коллекционера» — отдельный веб-сервис для переноса коллекций в локальное мобильное приложение DomCollection. Сервис развивается как курсовой проект по дисциплине «Методы и средства проектирования информационных систем». Мобильное приложение и сервис хранятся в разных репозиториях.

## Что реализовано в исходниках 0.1.0

1. Загрузка CSV, XLSX, JSON и структурированного TXT через веб-страницу без постоянного хранения файла на сервере; можно вставить текстовый список.
2. Предложение соответствия столбцов полям DomCollection и предварительный просмотр первых строк. Пользователь может изменить соответствие.
3. Пересчёт покупной цены из EUR в RUB по официальному курсу Банка России на дату курса, возвращённую его API. Исходная сумма и курс записываются в заметки модели.
4. Загрузка личных фото Hunt64 из `My Photo URL` и преобразование WebP/PNG/JPG в JPEG. Если фото отсутствует или недоступно, добавляется заглушка с пометкой.
5. Создание ZIP с `collection.json` и фото по формату, который принимает текущий DomCollection.
6. Админ-панель для учёта API-ключей согласившихся владельцев: отдельный админ-токен, шифрование ключей на диске, проверка ключа через официальный API OpenRouter, включение/выключение и удаление. Через один выбранный ключ можно распознать свободный текст моделью `openrouter/free`, просмотреть результат и передать его в обычный конвертер ZIP.

Если даты покупки нет, используется дата переноса с явной пометкой в заметках. `Date Added` из Hunt64 не считается датой покупки. Пустая покупная цена становится 0 ₽ с пометкой; оценочная стоимость из Hunt64 не используется как цена покупки.

Бесплатный ручной путь описан на странице `/guide`: пользователь сам обращается к DeepSeek, затем вставляет JSON на главной странице и получает ZIP. Автоматическое распознавание OpenRouter пока доступно только администратору, требует API-ключа и не проверялось с реальным ответом. Фото с произвольных сайтов и входные ZIP не поддерживаются. Платежи не подключены. Цена 139 ₽ за автоматическую конвертацию — предварительная гипотеза; перенос 5000 моделей за раз пока не реализован. Для защиты памяти небольшого сервера действуют лимиты: 8 МБ входного файла, 300 моделей, 100 МБ ZIP; для одного запроса OpenRouter — 20 000 символов и 100 моделей.

## Лабораторная работа 1

В опубликованной версии 0.0.1 были только Node.js/Express, первая страница и Dockerfile. Тег `semiys/mispisit-lab1:0.0.1` на Docker Hub **не содержит** новую конвертацию. Отчёт ЛР1 описывает состояние на момент сдачи; его не нужно менять из-за развития проекта.

## Работа со второго компьютера

Выполните инструкции [SECOND_COMPUTER_SETUP.md](SECOND_COMPUTER_SETUP.md). Пользователь сам создаёт коммиты и отправляет изменения в GitHub; не выполнять `git commit` или `git push` за него. После отправки можно клонировать репозиторий на второй компьютер и продолжить работу там.
