# Контекст проекта

## Назначение

«Хаб Коллекционера» — отдельный веб-сервис для переноса коллекций в мобильное приложение DomCollection. Он принимает таблицы Excel/CSV, текстовые файлы и вставленный текст (в том числе скопированные сообщения из Telegram). Фотографии необязательны. В дальнейшем сервис должен помочь сопоставить произвольные поля с форматом приложения и подготовить ZIP для импорта.

Мобильное приложение остаётся самостоятельным локальным приложением. Сервис — отдельный репозиторий и учебный проект по МиСПИСИТ.

## Планируемый сценарий

1. Пользователь загружает файл или вставляет текст; при желании добавляет фотографии.
2. Сервис предлагает сопоставление полей и предварительный просмотр результата. Нейросеть помогает распознать разные структуры входных данных.
3. Пользователь исправляет неоднозначности и подтверждает перенос.
4. Детерминированная часть валидирует данные и создаёт ZIP в формате импорта DomCollection. Для отсутствующих фотографий планируется изображение-заглушка; точный механизм ещё не реализован.
5. Пользователь скачивает ZIP и импортирует его в приложение.

Формат импорта нужно сверять с актуальным кодом мобильного приложения до реализации экспорта. Платежи и ИИ пока не подключены. Цена 149 ₽ за автоматическую конвертацию — предварительная гипотеза, не текущая функция.

## Работа со второго компьютера

Репозиторий можно добавить в GitHub Desktop, самостоятельно создать коммит и отправить на GitHub. Затем клонировать его на второй компьютер и открыть папку в Codex. Этот файл сохраняет основные решения даже при запуске нового чата. История чата и файлы проекта передаются отдельно: форк чата сам по себе не копирует рабочую папку.
