# Запуск сервиса на втором компьютере

Сервис можно проверять двумя способами. Выберите **один**; ставить и Docker, и Node.js не требуется.

## Вариант A — Docker в виртуальной машине

Нужно:

1. Работающий Docker Engine или Docker Desktop в виртуальной машине. У вас Docker там уже запускался — повторно устанавливать его не нужно.
2. Исходники репозитория `Semiys/collector-transfer-service` в виртуальной машине. Их можно получить через Git (`git clone`) или скачать ZIP репозитория с GitHub. Git не нужен, если скачали ZIP.
3. Интернет для первой сборки образа, курса ЦБ и загрузки личных фото Hunt64.

В каталоге репозитория выполните:

```sh
docker build -t collector-transfer-service:0.1.0 .
docker run --rm -p 8080:8080 collector-transfer-service:0.1.0
```

Откройте `http://localhost:8080` **в браузере той же виртуальной машины**. Если хотите открыть сервис с Windows-хоста, настройте проброс порта 8080 из виртуальной машины на хост.

## Вариант B — запуск без Docker

Нужно:

1. Node.js версии 24 с npm (npm входит в установщик Node.js).
2. Исходники репозитория через Git или ZIP.
3. Интернет при установке зависимостей, для курса ЦБ и фото Hunt64.

В каталоге репозитория:

```sh
npm ci
npm test
npm start
```

На Windows PowerShell, если команда `npm` заблокирована политикой выполнения, используйте `npm.cmd ci`, `npm.cmd test`, `npm.cmd start`. Затем откройте `http://localhost:8080`.

Если на Windows нужно сохранить место на диске C, **до** `npm.cmd ci` задайте кэш на диске D в этой сессии PowerShell:

```powershell
$env:npm_config_cache = 'D:\npm-cache'
npm.cmd ci
```

Это не меняет глобальные настройки npm. При запуске через Docker npm устанавливает зависимости внутри образа; место занимает хранилище Docker той виртуальной машины, где он запущен.

## Админ-панель API-ключей

Панель находится по адресу `http://localhost:8080/admin`. Она сохраняет список ключей, проверяет ключ по запросу через API OpenRouter и может распознать свободный текст через один явно выбранный ключ. Автоматического распределения между ключами нет. Добавляйте API-ключи отдельных владельцев, которые дали согласие. Не вводите логины и пароли OpenRouter. Для регистрации и создания собственного ключа используйте [OpenRouter](https://openrouter.ai/sign-up) и [страницу ключей](https://openrouter.ai/keys).

Для панели нужны два разных случайных значения. После сборки Docker-образа сгенерируйте их на втором компьютере:

```sh
docker run --rm collector-transfer-service:0.1.0 node -e "const c=require('node:crypto');for(const n of ['ADMIN_ACCESS_TOKEN','OPENROUTER_KEY_ENC_KEY'])console.log(n+'='+c.randomBytes(32).toString('hex'))"
```

Если работаете без Docker, ту же команду можно выполнить начиная с `node -e`. Скопируйте две полученные строки в файл `.env` в корне репозитория. Файл игнорируется Git; **не отправляйте его в чат и не добавляйте в репозиторий**. Сохраните резервную копию ключа шифрования в надёжном месте: без него уже записанные API-ключи восстановить нельзя.

Для Docker запускайте сервис с постоянным томом:

```sh
docker run --rm -p 8080:8080 --env-file .env -v collector-transfer-data:/app/data collector-transfer-service:0.1.0
```

Для запуска напрямую через Node.js 24 используйте `node --env-file=.env src/server.js`. Введите `ADMIN_ACCESS_TOKEN` на странице `/admin`; сам токен браузер не сохраняет. Список ключей хранится в зашифрованном файле в `data/` (Docker: `/app/data`) и не попадает в Git. При публичном размещении панели настройте HTTPS перед вводом токенов и API-ключей.

Для теста ИИ откройте `/admin`, нажмите «Открыть список», выберите включённый ключ, вставьте текст коллекции и нажмите «Распознать текст». Текст отправляется через OpenRouter выбранной бесплатной модели; уберите из него личные данные до отправки. После ответа нажмите «Проверить модели и подготовить ZIP»: откроется обычный экран переноса со всеми распознанными строками. Проверьте данные и валюту цены, подтвердите замечания, затем скачайте ZIP. Для публичных пользователей этот маршрут пока закрыт админ-токеном.

## Что устанавливать не нужно

Для обычного переноса файлов не нужны Android Studio, JDK, Gradle, база данных, платный ИИ или ключи OpenRouter. Для пробного распознавания свободного текста нужен API-ключ OpenRouter. Библиотеки из `package.json` устанавливаются **внутри каталога проекта** командой `npm ci` либо **внутри Docker-образа** командой `docker build`.

## Проверка

Загрузите CSV Hunt64 или тестовую XLSX/JSON, проверьте столбцы, курс ЦБ для EUR и скачайте ZIP. Бесплатный ручной сценарий для пользователей размещён на странице `/guide`: скопируйте промпт, получите JSON в DeepSeek, вставьте его на главной странице и скачайте ZIP после проверки. При недоступной ссылке Hunt64 сервис подставит заглушку и покажет номера строк. Импортируйте ZIP в DomCollection на тестовом телефоне. Повторный импорт добавляет те же модели ещё раз.

Текущие ограничения: до 8 МБ входного файла, до 300 моделей и до 100 МБ ZIP за один перенос. ИИ обрабатывает до 20 000 символов и 100 моделей за запрос; реальные ответы OpenRouter нужно проверить с вашим ключом. Фото из произвольных сайтов и входные ZIP пока не обрабатываются.
