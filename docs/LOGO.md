# Иконка сайта

«Хаб Коллекционера» — рабочее название сервиса переноса коллекций.

02.10.2026 по указанию пользователя точечный знак заменён иконкой мобильного приложения «Дом Коллекционера»: белые полки и предметы на голубом фоне.

`public/collector-logo.png` — присланный PNG 1024 × 1024, скопированный без изменения изображения. Файл используется в шапке всех семи страниц и как favicon. Иконка одинакова для светлой и тёмной темы. Старые SVG с точками удалены.

Изображение доступно по `/collector-logo.png`. Сервер разрешает его кеширование на сутки. Для страниц заказа и админки политика ресурсов разрешает изображения только с этого же сайта. Docker включает иконку через существующий `COPY public ./public`; отдельная установка не нужна.
