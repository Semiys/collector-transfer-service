Ключи распознавания · Groq

Ключи Groq

Добавляйте только API-ключи владельцев, которые согласились участвовать. Логины и пароли не нужны. Ключи сохраняются в зашифрованном файле, а в списке видны только последние четыре символа.

Выберите основной ключ. Если разрешите резервные ключи для конкретного запроса, сервис может переключиться на них при ограничении частоты. Результат нужно проверить перед созданием ZIP.

Модель пилота — openai/gpt-oss-120b. Создайте ключ в Groq Console → API Keys и вставьте его целиком, без слова Bearer. Лимиты общие для организации; несколько её ключей не увеличивают квоту. Старые ключи OpenRouter выключены для распознавания.

Перенести файл с помощью ИИ

Для проверки сервиса: CSV, XLSX, JSON, TXT или вставленный текст. До 300 непустых строк и 200 000 символов, файл до 8 МБ. В Excel читается первый заполненный лист с названиями столбцов в первой строке. Фото внутри Excel не извлекаются.

Обработка идёт частями в фоне. Можно обновить страницу: задание останется в памяти сервера. После перезапуска сервера его нужно создать заново. Очередь и обработка — до 15 минут; готовый результат доступен 10 минут. Исходники и результаты не записываются на диск.

Заказы автоматического переноса

Учёт заказов

Здесь сохраняются только номер, сумма и статусы заказа. Коллекции, файлы и фотографии в заказах не хранятся.

Оплата пока не подключена. Можно создать черновик и проверить, что он остаётся после перезапуска сервера. Это не запускает ИИ и не списывает деньги.

Быстрая проверка короткого текста

Распознать свободный текст

Для проверки вставьте небольшой список моделей или сообщения из Telegram. Текст будет отправлен модели openai/gpt-oss-120b через Groq. Начните с 2–3 моделей: бесплатный тариф ограничивает запросы и токены. Если в тексте есть личные данные, сначала удалите их.
