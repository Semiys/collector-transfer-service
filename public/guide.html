Перенести коллекцию бесплатно с помощью DeepSeek

Подойдёт для таблицы Excel, CSV, текстового списка или скопированных сообщений. DeepSeek поможет привести записи к одному виду. Наш сервис проверит результат и сделает ZIP для приложения DomCollection.

Есть обычная таблица Excel или CSV? Сначала попробуйте загрузить её напрямую. DeepSeek нужен, если таблица устроена необычно или данные записаны свободным текстом.

Весь путь: скопировать промпт → добавить свои данные в DeepSeek → скопировать JSON-ответ → вставить его на странице переноса → проверить модели → скачать ZIP.

1Подготовьте небольшой кусок коллекции

  1. Если у вас Excel или CSV, откройте таблицу. Выделите строку с названиями столбцов и несколько строк с моделями, затем скопируйте их. На Windows это Ctrl+C.
  2. Если у вас TXT или список в Telegram, скопируйте сообщения, где перечислены модели. Личную переписку, адреса и номера телефонов лучше убрать до отправки в сторонний сервис.
  3. Для первой проверки возьмите 3–5 моделей. Когда убедитесь, что всё правильно, переносите следующую часть. Длинный список удобнее делить примерно на 20–50 моделей за один ответ DeepSeek, чтобы ответ не оборвался.

Один ZIP сейчас содержит не более 300 моделей. Если моделей больше, делайте несколько частей без повторяющихся строк. Импорт одной и той же части дважды создаст дубликаты.

2Скопируйте готовый запрос

Нажмите кнопку ниже. Откройте официальный чат DeepSeek, войдите в аккаунт при необходимости и вставьте запрос в поле сообщения. На Windows вставка — Ctrl+V.

Важно: после строки «ДАННЫЕ КОЛЛЕКЦИИ:» вставьте скопированные строки своей коллекции и только потом отправьте сообщение DeepSeek. Без ваших строк нейросети нечего преобразовывать.

3Скопируйте ответ DeepSeek

Дождитесь полного ответа. Он должен начинаться с [ и заканчиваться ]. Скопируйте весь JSON — текст внутри этих скобок. Если DeepSeek поместил его в блок с пометкой json, можно скопировать блок целиком: сайт уберёт эту обёртку.

Сравните число записей в ответе с числом моделей, которые вы отправили. Если ответ оборвался, не используйте его: отправьте меньшую часть списка. Если DeepSeek написал обычный текст вместо JSON, попросите его: «Повтори ответ только как корректный JSON-массив без пояснений».

4Проверьте данные и скачайте ZIP

  1. Вернитесь на страницу переноса. Вставьте ответ в поле «Или вставьте текст / JSON из DeepSeek».
  2. Нажмите «Проверить JSON из DeepSeek». Появится таблица распознанных моделей.
  3. Проверьте число моделей, названия, бренд, масштаб, категорию, цену, дату и заметки. Выберите валюту цен: рубли или евро. Если DeepSeek ошибся, исправьте ответ в чате и вставьте новый JSON.
  4. Подтвердите предупреждение о проверке ИИ и нажмите «Скачать ZIP для DomCollection». Сервис создаст нужный архив сам: вручную упаковывать JSON не надо.
Открыть страницу переноса

Если цена отсутствует, в приложении будет 0 ₽ с пометкой в заметках. Если нет даты покупки, будет дата переноса с пометкой. Если нет доступного фото, появится заглушка. Перед скачиванием обратите на это внимание.

5Импортируйте ZIP в приложение

  1. Передайте скачанный файл dom_collection_transfer.zip на телефон любым удобным способом. Не распаковывайте и не перепаковывайте его.
  2. В DomCollection откройте «Профиль» → «Импорт коллекции» и выберите этот ZIP.
  3. После импорта проверьте несколько моделей, особенно цены и фотографии.

Если что-то не получилось

Сайт пишет, что JSON не читается

Скопируйте ответ полностью: от первой квадратной скобки [ до последней ]. Проверьте, что DeepSeek дописал ответ до конца. Если нет — попросите обработать меньшую часть списка.

Сайт нашёл меньше моделей, чем должно быть

Не скачивайте ZIP. Сравните исходные строки с ответом DeepSeek. Повторите запрос с меньшей частью и явно укажите, какие модели пропущены.

Валюта или цена неверна

В одном переносе выберите одну валюту. Для списка со смешанными валютами разделите модели по валютам на разные части. Проверьте цену до скачивания ZIP.

Фотографии не перенеслись

Сейчас сервис умеет получать личные фото по ссылкам Hunt64. Встроенные в Excel картинки и файлы фото из сообщений DeepSeek не передаёт в ZIP. Для таких моделей добавляется заглушка; фото можно добавить в приложении позже.

Моделей больше 300

Разделите коллекцию на несколько частей. Для каждой получите отдельный JSON и ZIP, затем импортируйте архивы по одному. Не повторяйте одну и ту же модель в разных частях.
