# Шрифты сайта

Шрифты взяты из ресурсов мобильного приложения DomCollection для общего визуального стиля.

- `Montserrat-VariableFont_wght.ttf` — [Montserrat](https://github.com/JulietaUla/Montserrat), SIL Open Font License 1.1. Текст лицензии: `OFL-Montserrat.txt`.
- `inter_regular.ttf` и `inter_medium.ttf` — [Inter](https://github.com/rsms/inter), SIL Open Font License 1.1. Текст лицензии: `OFL-Inter.txt`.
